# 16md5

一个使用 HTML 和 JavaScript 编写的字符串转换小工具。在浏览器中输入字符串，即可得到 **16 位 MD5，并将结果中的第一个字母转为大写**。

## 使用方法

1. 下载本仓库，或通过 Git 克隆：

   ```sh
   git clone https://github.com/minwiki7456/16md5.git
   ```

2. 用浏览器打开仓库中的 `index.html`。
3. 在 **Input** 输入框中填写要转换的字符串。
4. 点击 **Calculate**，在 **Output** 下查看结果。

无需安装依赖、构建项目或启动后端服务。页面通过 CDN 加载 MD5 库，因此使用时需要能够访问 `cdnjs.cloudflare.com`。

## 转换规则

程序按照以下顺序处理输入：

1. 使用 `blueimp-md5` 计算字符串的 32 位小写 MD5 十六进制值。
2. 使用 `substring(8, 24)` 截取中间 16 个字符，即从第 9 个字符到第 24 个字符（含首尾）。
3. 从左到右找到截取结果中的第一个字母（`a`–`f`），仅将该字母转为大写，其余字符保持不变。如果没有字母，则保持原样。

例如，输入 `hello`：

```text
32 位 MD5：  5d41402abc4b2a76b9719d911017c592
中间 16 位： bc4b2a76b9719d91
最终输出：  Bc4b2a76b9719d91
```

“第一个字母”不一定是结果的第一个字符；如果结果以数字开头，程序会继续查找后面的字母。

### 输入输出示例

| 输入字符串 | 最终输出 |
| --- | --- |
| `hello` | `Bc4b2a76b9719d91` |
| `123456` | `49Ba59abbe56e057` |
| `abc` | `3Cd24fb0d6963f7d` |
| 空字符串 | `8F00b204e9800998` |

输入中的空格会参与计算，程序不会自动去除首尾空格。空输入也可以计算。

## 项目结构与依赖

```text
16md5/
├── index.html  # 页面、输入输出元素及转换逻辑
└── README.md   # 使用说明
```

核心逻辑位于 `index.html` 的 `calculateMD5()` 函数中。页面通过以下地址加载 [blueimp-md5 2.18.0](https://github.com/blueimp/JavaScript-MD5/tree/2.18.0)：

```text
https://cdnjs.cloudflare.com/ajax/libs/blueimp-md5/2.18.0/js/md5.min.js
```

输入值由页面中的 JavaScript 在浏览器本地处理；当前应用代码没有上传输入值的逻辑。加载第三方脚本需要联网。

## 适用范围

此工具用于生成上述固定格式的字符串摘要。这种截取 MD5 并修改大小写的方式不适合安全地存储密码，也不应作为密码加密方案。
